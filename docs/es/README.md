# AI Visibility Dashboard — Documentación

🇬🇧 [Read in English](../en/README.md) · [Volver al proyecto](../../README.es.md)

AI Visibility Dashboard for Mencoro añade un widget de **Visibilidad en IA** al Escritorio de WordPress: cómo mencionan tu marca ChatGPT, Claude, Perplexity y Google IA, con los datos de tu proyecto de Mencoro.

## Respuestas rápidas

- **¿Necesito Mencoro?** Sí: el plugin muestra los datos que recoge tu proyecto de Mencoro. → [Primeros pasos](primeros-pasos.md#qué-necesitas)
- **¿Puede verlo mi cliente sin la clave?** Sí. → [Para agencias](agencias.md#enséñale-el-widget-al-cliente-no-la-clave)
- **¿Ralentiza mi web?** No: solo funciona en el panel, sin JavaScript y con caché de 6 horas. → [Privacidad y seguridad](privacidad-y-seguridad.md#parte-pública-y-código-de-terceros)
- **¿Por qué no coinciden las cifras con las de Mencoro?** Casi siempre es por los motores, el periodo o la caché. → [Solución de problemas](solucion-de-problemas.md#las-cifras-no-coinciden-con-las-de-mencoro)
